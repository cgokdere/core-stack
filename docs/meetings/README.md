# Weekly meetings

Every week from Week 3 to Week 13 the team meets and **commits the meeting notes** here.

* One file per meeting: `week-NN_YYYY-MM-DD.md` (for example `week-04_2026-10-21.md`).
* Start from [TEMPLATE.md](TEMPLATE.md).
* Add the notes through a pull request like any other change, with the Jira key in the message.
* Write only what really happened.

Our team has no SENG 440 test and quality students, so these are the development team's own meetings.
